Opens every section with the brand's rhythm: gold uppercase eyebrow → uppercase display heading → italic serif lede.

```jsx
<SectionHeading eyebrow="The process" title="How it works" lede="Simple, virtual, and built around your schedule." tone="dark" />
```

The lede is Libre Baskerville italic — that serif italic is the one warm counterweight to all the uppercase
Archivo, so do not swap it for the sans. Use `tone="dark"` inside navy bands.
